# Hasard

Pour laisser faire le hasard dans NeoBase : une roue avec tes propres choix, des dés, pile ou face,
et un tirage de nombre.

## Installer

Dans NeoBase : **NeoStore → À découvrir → Hasard → Installer**.

Développer un plugin : voir le [SDK NeoBase](https://github.com/NDesumeur/neobase-sdk).
